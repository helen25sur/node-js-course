# Shop Database
A Node.js backend API for managing products and users.

## Description
This project is a RESTful API built with Node.js and Express. It allows product management for a small e-commerce application.

## Tech Stack
- Node.js
- Express.js
- MongoDB + Mongoose
- Docker (optional)

## Getting Started

1. Клонуй репозиторій:
```bash
git clone https://github.com/helen25sur/node-js-course.git
cd ./node-js-course/homework-lecture-13/31
```

2. Встанови залежності:
```bash
npm install
```

3. Створи .env файл:
```
cp .env.example .env
```
4. Запусти локально:
```
npm run dev
```
5. ⚙️ Налаштування `.env`
```
- MONGO_URI=mongodb://localhost:27017
- MONGO_DB_NAME=dbName
```
